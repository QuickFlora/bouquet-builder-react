# Bouquet Builder (React + Vite)

Sunflower Technologies Bouquet Builder POC. Flat single-level Vite project.

## Local
npm install
npm run dev

## Build
npm run build   # -> dist/

## AWS Amplify
Connect this repo in Amplify Hosting. Auto-detects Vite via amplify.yml
(build: npm run build, output: dist). No env vars required.
